### 3b. 関係節レベルの整理 — **画像10枚の生成待ち**(`next` ブランチで作業中、本番は v36)

方針: 関係節の対は **前半の出来事(誰が誰に)が2枚とも同じ** で、後半の状態にある人物だけが違う形にそろえる(前半まで入れ替わると語順レベルと区別がつかない、というユーザー指摘)。

- 前半まで入れ替わっていた4組(たたいた・ぶつかった・傘を貸した・押されている)は単文レベルへ移動済み(絵はそのまま活用)
- 2文を「前半が同じ」形に書き換え済み(助けた→「男の子が助けた女の子が…」、電車→「男の子が手を振っているお母さんが…」)。この2枚は絵の作り直しが必要
- 差し替え4組(8枚)の生成リスト: `data/pending/scene-relative2.json`。指示文はガイド §11.3(作り直し2枚の指示も同じ節)
- [ ] Codex で新規8枚 + 上書き2枚を生成 → `node scripts/optimize-images.mjs images/scene` → `node scripts/merge-pending.mjs`
- [ ] Windows で確認して `next` にプッシュ → Mac で音声生成(未生成ぶんすべて。`git checkout next` で) → `next` にプッシュ
